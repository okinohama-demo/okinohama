# おきのはま製パン

徳島市沖浜町にある架空のパン屋「おきのはま製パン」の制作見本です。

- 公開予定URL：<https://okinohama-demo.github.io/okinohama/>
- 公開方式：GitHub Pages（`main` ブランチのルート）
- 構成：静的HTML／CSS／JavaScript
- ビルド：不要

## 公開前の確認

```powershell
node --test tests\okinnohama-structure.test.mjs
```

このテストは親ワークスペース `C:\Users\User\Desktop\claude` から実行します。

## 見本について

店名、人物、住所、商品、価格、営業情報、お客さまの感想は実在しません。注文画面は操作見本で、情報の送信・保存・決済は行いません。写真の出典は `CREDITS.md` に記載しています。
